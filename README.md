## 💻 Used Technologies

-   **Frontend Framework:** Bootstrap 5
-   **JavaScript Library:** jQuery
-   **CSS Preprocessor:** SCSS
-   **Animation Libraries:** Animate.css, WOW.js
-   **Carousel:** Owl Carousel
-   **Lightbox:** Lightbox.js
-   **Isotope:** For portfolio filtering
-   **Waypoints:** For scroll animations

<hr/>

## ✨ Key Features

-   **Responsive Design:** Mobile-first approach with Bootstrap 5
-   **Modern UI/UX:** Clean and professional interface design
-   **Interactive Elements:** Smooth animations and transitions
-   **Portfolio Showcase:** Filterable portfolio with isotope
-   **Testimonials Carousel:** Dynamic testimonial display
-   **Contact Forms:** User-friendly contact interface
-   **SEO Optimized:** Built with SEO best practices
-   **Cross-browser Compatible:** Works on all modern browsers
